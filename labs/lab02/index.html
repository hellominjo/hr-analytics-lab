    Lab 02. Employee Performance Prediction

    HR 특성을 활용한 이항 로지스틱 회귀분석 및 고성과 확률 예측

    Tools: R · RStudio · Excel
    Methods: 이항 로지스틱 회귀분석 · 오즈비(OR) · GVIF · 모형 적합도 검정 · 분류 성능 평가
    Keywords: HR Analytics · Employee Performance · Logistic Regression · Classification

    1. Overview | 분석 개요

    직원의 HR 특성과 고성과 여부의 관계를 분석하고, 고성과 확률을 예측하는 모형을 구축합니다. 독립변수는 결혼여부, 근무시간, 근태사고율, 나이, 리더역량, 성별, 연봉, 연차, 조직적합도, 직무만족도, 학력입니다.

    연구 질문: 직원의 HR 특성은 고성과 여부와 어떤 관계가 있으며, 이를 활용하여 고성과자가 될 확률을 예측할 수 있는가?

    2. Dataset | 데이터셋

    • 데이터: ch3_performance.xlsx(모형 구축), test.xlsx(신규 직원 예측·검증)
    • 출처: HR 데이터애널리틱스 수업 분석 데이터
    • 종속변수: 성과(1 = 고성과자, 0 = 저성과자)
    • 전처리: 결혼여부·성별·학력을 범주형으로 변환(기준범주: 결혼여부 M, 성별 F, 학력 1), 수치형 변수는 원본 값 사용

    3. Methodology | 분석 방법

    1. glm(family = binomial)으로 이항 로지스틱 회귀모형 구축
    2. 회귀계수에 지수함수를 적용해 오즈비(OR)와 95% 신뢰구간 산출
    3. GVIF로 다중공선성 진단
    4. 우도비 카이제곱 검정과 AIC로 모형 적합도 확인
    5. 예측확률 0.5를 기준으로 분류하고 혼동행렬로 정확도·민감도·특이도 평가
    6. 신규 직원 5명의 고성과 확률 예측 후 실제 성과와 비교

    4. Generative AI Prompts | 생성형 AI 활용

    R 코드 작성, 로지스틱 회귀분석과 오즈비 산출, 분류 성능 평가, 신규 직원 예측 결과의 Excel 저장 절차를 구성하는 데 생성형 AI를 활용한 실습입니다. 0/1 코딩과 기준범주 설정, 혼동행렬의 실제값·예측값 방향 등은 R 출력값을 기준으로 직접 확인해야 합니다.

    5. Results | 분석 결과

    평가 지표 결과 해석
    정확도(Accuracy) 72.4% 전체 직원의 72.4%를 정확하게 분류
    민감도(Sensitivity) 54.7% 실제 고성과자의 54.7%를 식별
    특이도(Specificity) 84.1% 실제 저성과자의 84.1%를 식별

    저성과자 식별 성능에 비해 고성과자 식별 성능이 상대적으로 낮았습니다. 신규 직원 5명 중 4명의 성과를 정확하게 예측했으며, 실제 고성과자인 직원 3은 예측확률 0.343으로 저성과자로 분류되었습니다.

    6. HR Insights | HR 관점의 시사점

    • HR 특성으로 고성과 확률을 추정할 수 있지만, 고성과자 탐지가 목적이라면 분류 기준값 조정이 필요합니다.
    • 정확도 하나보다 민감도·특이도를 함께 보고 모형의 활용 가능성을 판단해야 합니다.
    • 예측 결과는 인재 육성 및 성과관리의 보조자료로만 활용하고, 데이터 편향·개인정보 보호·평가 공정성을 함께 고려해야 합니다.
    • 변수 간 관계는 인과관계가 아니며, 신규 직원 검증 사례가 5명으로 적어 일반화에 주의가 필요합니다.

    7. Analysis Workflow | 분석 과정

    Excel 불러오기 → 변수 설정 → 로지스틱 회귀 → 오즈비 → 다중공선성·적합도 검정 → 분류 성능 평가 → 신규 직원 예측 → 결과 저장

    이 페이지는 웹 공개용 요약 문서입니다. 원본 R 스크립트와 결과 Excel은 프로젝트의 Lab 02 디렉터리에서 관리합니다.
