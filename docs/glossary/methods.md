# Methods | 분석방법 및 기술 용어

피플 애널리틱스에서 데이터의 특성을 파악하고, 집단 간 차이와 변수 간 관계를 검증하며, 직원의 행동과 성과를 예측하는 데 활용하는 주요 통계 분석 기법을 정리합니다.

## 1. Descriptive Statistics | 기술통계

| 용어 | 의미 | HR 분석 예시 |
|---|---|---|
| **Descriptive Statistics (기술통계)** | 데이터의 주요 특징을 수치로 요약하는 방법 | 직원의 평균 연령 및 근속연수 분석 |
| **Mean (평균)** | 관측값의 합을 관측치 수로 나눈 값 | 고성과자의 평균 역량 점수 |
| **Median (중앙값)** | 데이터를 크기순으로 정렬했을 때 중앙에 위치하는 값 | 직원 연봉의 중앙값 |
| **Standard Deviation (표준편차)** | 관측값이 평균을 중심으로 흩어진 정도 | 직원별 직무만족도 점수의 분포 |
| **Variance (분산)** | 평균으로부터의 편차 제곱을 요약한 통계량 | 부서별 역량평가 점수의 변동성 |
| **Mean Difference (평균 차이)** | 두 집단 평균의 차이 | 고성과자와 저성과자의 성실성 평균 차이 |
| **Frequency (빈도)** | 특정 범주에 해당하는 관측치 수 | 부서별 직원 수 |
| **Percentage (비율)** | 전체 관측치 중 특정 범주가 차지하는 비중 | 고성과자 비율 |

## 2. Statistical Inference | 통계적 추론

| 용어 | 의미 | HR 분석 예시 |
|---|---|---|
| **Hypothesis Testing (가설검정)** | 표본 데이터를 활용해 모집단에 관한 가설을 검정하는 과정 | 성과집단 간 역량 점수 차이 검정 |
| **Null Hypothesis (귀무가설)** | 집단 간 차이나 효과가 없다는 기본 가설 | 두 집단의 평균은 동일함 |
| **Alternative Hypothesis (대립가설)** | 집단 간 차이나 효과가 존재한다는 가설 | 두 집단의 평균은 서로 다름 |
| **Significance Level (유의수준)** | 귀무가설이 참일 때 잘못 기각할 위험의 허용 기준 | α = 0.05 |
| **p-value (유의확률)** | 귀무가설이 참일 때 관측 결과만큼 또는 더 극단적인 결과가 나타날 확률 | AI 불안 평균 차이의 통계적 유의성 판단 |
| **Test Statistic (검정통계량)** | 가설검정에 활용하는 표본 기반 통계량 | t값, F값 |
| **Degrees of Freedom (자유도)** | 검정통계량의 분포를 결정하는 정보량 관련 값 | Welch t-검정의 자유도 |
| **Confidence Interval (신뢰구간)** | 모집단 모수 추정의 불확실성을 나타내는 구간 | 평균 차이의 95% 신뢰구간 |

## 3. Statistical Methods | 통계 분석 기법

| 용어 | 의미 | HR 분석 예시 |
|---|---|---|
| **Independent Samples t-test (독립표본 t-검정)** | 독립된 두 집단의 평균 차이를 검정하는 방법 | 고성과자와 저성과자의 성실성 점수 비교 |
| **Paired Samples t-test (대응표본 t-검정)** | 동일 대상의 사전·사후 평균 차이를 검정하는 방법 | 교육 전후 직무역량 점수 비교 |
| **Welch's t-test (Welch t-검정)** | 두 집단의 분산이 같다는 가정 없이 평균 차이를 검정하는 방법 | 50세 미만과 50세 이상 AI 불안 비교 |
| **ANOVA (분산분석)** | 세 집단 이상의 평균이 동일한지 검정하는 방법 | 연령대별 직무만족도 비교 |
| **Welch's ANOVA (Welch 분산분석)** | 집단 간 등분산을 가정하지 않는 다집단 평균 비교 방법 | 20~60대 AI 불안 비교 |
| **Post-hoc Test (사후검정)** | 전체 집단 비교 후 어떤 집단 사이에 차이가 있는지 확인하는 방법 | 연령대별 평균 차이 확인 |
| **Games-Howell Test (Games-Howell 검정)** | 등분산 가정이 어려운 다집단의 사후비교 방법 | 연령대별 프라이버시침해불안 비교 |
| **Effect Size (효과크기)** | 집단 차이나 변수 관계의 크기를 나타내는 지표 | AI 불안의 실질적인 집단 차이 확인 |
| **Cohen's d (Cohen의 d)** | 두 집단 평균 차이를 표준화한 효과크기 | 연령집단 간 AI 불안 효과크기 |
| **Regression Analysis (회귀분석)** | 설명변수와 결과변수의 관계를 분석하거나 결과를 예측하는 방법 | 직무역량과 성과의 관계 분석 |
| **Logistic Regression (로지스틱 회귀분석)** | 범주형 결과의 발생 확률을 예측하는 회귀분석 방법 | 고성과자 여부 예측 |

## 4. Model Evaluation | 모형 평가

| 용어 | 의미 | HR 분석 예시 |
|---|---|---|
| **Odds Ratio (오즈비)** | 설명변수 변화에 따른 사건 발생 오즈의 상대적 변화 | HR 특성별 고성과 오즈 비교 |
| **Multicollinearity (다중공선성)** | 설명변수들 사이에 강한 선형 관계가 존재하는 현상 | HR 평가 변수 간 중복 정보 확인 |
| **VIF / GVIF (분산팽창계수)** | 다중공선성을 진단하는 지표 | 회귀모형의 설명변수 진단 |
| **Likelihood Ratio Test (우도비 검정)** | 두 중첩 모형의 적합도를 비교하는 검정 | 영모형과 HR 성과 예측모형 비교 |
| **AIC (아카이케 정보 기준)** | 모형 적합도와 복잡도를 함께 고려하는 비교 지표 | 성과 예측모형 비교 |
| **Confusion Matrix (혼동행렬)** | 실제 분류와 예측 분류를 교차 비교한 표 | 고성과·저성과 예측 결과 확인 |
| **Accuracy (정확도)** | 전체 예측 중 정확하게 분류한 비율 | 전체 직원 성과 분류 정확도 |
| **Sensitivity (민감도)** | 실제 양성 중 양성으로 정확히 분류한 비율 | 실제 고성과자 탐지율 |
| **Specificity (특이도)** | 실제 음성 중 음성으로 정확히 분류한 비율 | 실제 저성과자 식별률 |
| **Classification Threshold (분류 기준값)** | 예측확률을 범주로 변환하는 기준 | 고성과 확률 0.5 이상을 고성과로 분류 |

## 5. Analysis Guide | 분석 방법

| 분석 목적 | 추천 분석 방법 | HR 활용 사례 |
|---|---|---|
| 데이터의 특성 요약 | 기술통계 | 직원 연령 및 역량평가 평균 |
| 두 독립집단의 평균 비교 | t-검정 / Welch t-검정 | 고성과자와 저성과자 비교 |
| 동일 대상의 사전·사후 비교 | 대응표본 t-검정 | 교육 프로그램 효과 분석 |
| 세 집단 이상의 평균 비교 | ANOVA / Welch ANOVA | 연령대별 AI 불안 비교 |
| 다집단 간 개별 차이 확인 | 사후검정 | Games-Howell 연령대별 비교 |
| 평균 차이의 크기 측정 | Cohen's d | AI 불안 효과크기 분석 |
| 변수와 결과 간 관계 분석 | 회귀분석 | HR 특성과 직원 성과의 관계 |
| 이진 결과의 확률 예측 | 이항 로지스틱 회귀분석 | 고성과자 확률 예측 |
