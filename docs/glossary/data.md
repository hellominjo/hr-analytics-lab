# Data | 데이터 기초 용어사전

피플 애널리틱스 분석에 필요한 기본 데이터 용어를 정리합니다.

| 용어 | 의미 | HR 분석 예시 |
|---|---|---|
| **Dataset (데이터셋)** | 분석을 위해 수집·정리한 데이터 집합 | 직원별 설문 및 성과 데이터 |
| **Observation (관측치)** | 분석 대상에 해당하는 개별 기록 | 직원 한 명의 평가 기록 |
| **Variable (변수)** | 분석 대상의 특성을 나타내는 항목 | 연령, 성과, AI 불안 점수 |
| **Independent Variable (독립변수)** | 결과를 설명하거나 예측하는 데 사용하는 변수 | 연령집단 |
| **Dependent Variable (종속변수)** | 설명하거나 비교하려는 결과변수 | 학습불안 점수 |
| **Categorical Variable (범주형 변수)** | 대상을 범주로 구분하는 변수 | 50세 미만 / 50세 이상 |
| **Sample Size (표본 수)** | 분석에 포함된 관측 대상의 수 | 집단별 응답자 수(N) |
| **Data Preprocessing (전처리)** | 분석에 적합하도록 데이터를 정리·변환하는 과정 | 설문 문항 평균 계산 및 연령집단 생성 |
