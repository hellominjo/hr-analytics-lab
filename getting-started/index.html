    Getting Started

    피플 애널리틱스(People Analytics)의 기본 개념과 데이터 분석 방법 이해 및 R과 RStudio를 활용해 HR 데이터 분석방법을 설명합니다.

    Domain: People Analytics · Human Resources
    Tools: R · RStudio · Excel
    Focus: HR Data · Descriptive Statistics · Statistical Analysis · Decision Making

    1. Introduction | 피플 애널리틱스의 이해

    1.1 People Analytics란?

    People Analytics는 단순히 인사 데이터를 분석하는 것이 아니라, 분석 결과를 조직의 의사결정과 연결하는 과정입니다.

    조직 구성원과 관련된 데이터를 수집·정리하고, 통계적 분석을 통해 인사관리 문제를 이해하며, 분석 결과를 채용·육성·성과관리 등 HR 의사결정에 활용합니다.

    분석의 흐름

    HR 문제 정의 → 데이터 이해 및 수집 → 전처리 → 통계 분석 → 결과 해석 → 의사결정 지원

    1.2 주요 분석 방향

    분석 영역 주요 질문 활용 사례
    인재 채용·선발 어떤 평가 요소가 입사 후 성과와 관련되는가? 채용 평가와 성과의 관계 분석
    교육·역량 개발 교육 전후 역량은 달라졌는가? 교육 효과 비교
    성과관리 어떤 특성이 고성과 가능성과 관련되는가? 직원 성과 예측
    *보상관리 보상 수준과 조직 성과 사이에 어떤 관계가 있는가? 보상 데이터 탐색
    직원 유지 어떤 요인이 이직 및 근속과 관련되는가? 이직 관련 요인 탐색
    조직문화·몰입 구성원 경험은 집단에 따라 다른가? 직무만족도 및 조직문화 분석

    분석 원칙: 통계적 관련성이 확인되었다고 해서 곧바로 인과관계가 입증되는 것은 아닙니다. 결과를 해석할 때 데이터의 특성과 HR 맥락을 함께 고려합니다.

    2. Data | 분석 데이터의 이해

    2.1 HR 데이터의 종류

    데이터 유형 변수 예시 분석 목적
    인적 특성 나이, 성별, 학력, 결혼여부 집단별 특성 파악
    근무·경력 근무시간, 연차, 근태사고율 근무 특성과 성과의 관계 탐색
    평가·역량 리더역량, 조직적합도, 성실성, 팀워크 역량 및 성과 관련 요인 분석
    인식·설문 직무만족도, 학습불안, 직무대체불안, 프라이버시침해불안 구성원 경험 및 인식 비교
    결과 변수 고성과 여부(0/1), 평가 점수 성과 비교 및 예측

    2.2 데이터 구조와 변수

    일반적으로 데이터셋의 행(Row)은 관측치, 열(Column)은 변수를 나타냅니다. 직원별 데이터에서는 직원 한 명이 한 행에 해당할 수 있지만, 동일 직원의 여러 시점 기록이 있다면 관측치 수와 직원 수는 달라집니다.

    • 독립변수(Independent Variable): 결과를 설명하거나 예측하는 데 사용하는 변수
    • 종속변수(Dependent Variable): 설명하거나 예측하려는 결과 변수
    • 범주형 변수(Categorical Variable): 성별, 학력, 고성과 여부 등 범주로 구분되는 변수
    • 수치형 변수(Numeric Variable): 나이, 근무시간, 평가 점수 등 숫자로 표현되는 변수
    • 표본 수(N): 분석에 포함된 관측치 수

    2.3 분석 전 데이터 확인

    1. 변수명과 변수 유형 확인
    2. 결측치·중복 기록 점검
    3. 범주형 변수의 코딩과 기준범주 확인
    4. 설문 척도의 평균 계산 및 필요한 역코딩 확인
    5. 개인 식별정보 및 민감한 인사정보의 처리 적절성 검토

    3. Methodology | 분석 방법

    3.1 기술통계(Descriptive Statistics)

    기술통계는 데이터의 특징을 수치로 요약하여 분석 대상을 이해하는 첫 단계입니다. 이후의 가설검정이나 예측 분석을 수행하기 전에 분포와 집단별 차이를 살펴볼 수 있습니다.

    지표 영문 의미
    표본 수 N 분석에 포함된 관측치 수
    평균 Mean 관측값의 산술평균
    표준편차 Standard Deviation (SD) 값들이 평균 주변에 퍼진 정도
    분산 Variance 평균으로부터의 편차 제곱을 요약한 값
    평균 차이 Mean Difference 두 집단 평균의 차이
    빈도·비율 Frequency / Percentage 범주별 관측치 수와 구성 비율

    HR 분석 예시: 고성과자와 저성과자의 성실성 점수에 대해 집단별 N, Mean, SD를 산출하여 차이를 탐색합니다. 단, 평균 차이만으로 통계적 유의성을 판단할 수는 없습니다.

    3.2 목적에 따른 통계 분석 기법

    분석 목적 분석 방법 예시
    데이터 요약 기술통계 직원 역량평가 평균·표준편차
    독립된 두 집단 평균 비교 독립표본 t-검정 고성과자 vs 저성과자
    등분산을 가정하지 않는 두 집단 비교 Welch's t-test 50세 미만 vs 50세 이상 AI 불안
    동일 대상의 전후 비교 대응표본 t-검정 교육 전후 역량 변화
    세 집단 이상 평균 비교 ANOVA / Welch's ANOVA 연령대별 AI 불안
    집단 간 개별 차이 확인 Games–Howell 사후검정 연령대별 사후 비교
    두 집단 평균 차이의 크기 Cohen's d AI 불안의 효과크기
    이진 결과의 확률 예측 이항 로지스틱 회귀분석 고성과자(1) 확률 예측

    분석에서는 p-value뿐 아니라 효과크기, 신뢰구간, 모형의 분류 성능 등을 목적에 맞게 함께 확인합니다.

    4. Analysis Environment | 분석 환경

    4.1 분석 도구

    • R : 데이터 처리, 통계 분석, 시각화에 사용하는 프로그래밍 언어
    • RStudio : R 코드를 작성·실행하고 데이터와 분석 결과를 확인하는 통합 개발 환경(IDE)
    • Excel : 강의 실습 데이터와 분석 결과를 관리하는 파일 형식 (.xlsx)

    4.2 설치 및 실행

    1. R 공식 사이트(CRAN)에서 R 설치
    2. RStudio Desktop 설치
    3. RStudio를 실행하고 분석 프로젝트 폴더 열기
    4. 필요한 패키지를 설치하고 Excel 데이터 불러오기
    # 최초 1회 패키지 설치
install.packages(c("readxl", "dplyr", "writexl", "car"))

# 패키지 불러오기
library(readxl)
library(dplyr)
library(writexl)
library(car)

# Excel 파일 불러오기: 파일 선택 창 사용
df <- read_excel(file.choose())

# 데이터 구조 및 기초 통계 확인
str(df)
summary(df)

    4.3 기술통계 실습 예시

    다음 코드는 실제 데이터 파일 없이도 실행할 수 있는 예시 데이터를 사용합니다.

    # Language: R

# 실습용 예시 데이터 (실제 연구 데이터 아님)
example_df <- data.frame(
  성과 = c(1, 0, 1, 0, 1, 0),
  성실성 = c(4.6, 3.2, 4.2, 3.8, 4.8, 3.5)
)

# 성과 집단별 표본 수, 평균, 표준편차
example_df %>%
  group_by(성과) %>%
  summarise(
    N = n(),
    Mean = mean(성실성, na.rm = TRUE),
    SD = sd(성실성, na.rm = TRUE),
    .groups = "drop"
  )

    5. Analysis Workflow | 분석 절차

    1. 문제 정의: HR 의사결정과 연결되는 질문 설정
    2. 데이터 이해: 데이터 출처, 관측치, 변수 및 측정 방식 확인
    3. 전처리: 결측치 처리, 범주형 코딩, 척도 구성
    4. 기술통계: 표본 특성, 평균, 표준편차, 분포 확인
    5. 통계 분석: 연구 질문에 적합한 검정·예측 모형 적용
    6. 결과 검증: 통계적 유의성, 효과크기, 예측 성능 및 한계 점검
    7. HR 인사이트: 조직 의사결정에 활용 가능한 시사점 도출
